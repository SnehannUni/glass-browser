## Hinweise für die Zertifizierung (Notes for certification)

Winter Browser is a web browser built on Microsoft Edge WebView2 (Chromium engine), in line with policy 10.2.1. It is a
packaged Win32 desktop app, so it requires `runFullTrust`. It registers as a handler for http/https and .htm/.html/.xhtml/.pdf
via the package manifest only, and never changes defaults itself. "Set as default browser" opens Windows Settings.
The app does not update itself; updates come through the Store only. No account or sign-in is needed to test it.
The mail view shows the providers' regular web sign-in pages. Signing in there is optional.
